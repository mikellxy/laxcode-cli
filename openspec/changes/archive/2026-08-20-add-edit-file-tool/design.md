## Context

见 proposal.md - Why。现状约束：write_file 承担全量写入且无增量能力；[safeJoinWorkDir](../../../internal/tools/base.go) 已提供路径防护可直接复用；工具经 `NewDefaultRegistry` 注册即可被 MainLoop 使用；LLM 返回的 `old_text` 与文件实际字节存在换行符、首尾空白、缩进三类常见漂移。

## Goals / Non-Goals

**Goals:**

- 让模型以最小 token 完成局部修改，且在 old_text 格式漂移下仍高成功率
- 失败反馈可直接驱动模型自我修正（扩大上下文 / 重新读取）

**Non-Goals:**

- 维护 CRLF 文件的一致性（混合换行符与大 diff 已接受为已知限制）
- 保持 L4 命中时的缩进美观（缩进以 new_text 为准）
- 并发编辑保护、文件锁（与 write_file 保持同等水平）

## Decisions

### D1: 四级降级匹配而非单一精确匹配

精确匹配对 LLM 输出过脆是本工具的核心失败模式。四级降级按"漂移类型"逐层放宽：字节级 → 换行归一化 → 首尾空白容忍 → 行级 trim 滑窗，每层只解决一类明确漂移，可预期、可测试。

- 替代方案：正则或编辑距离等模糊匹配——误匹配不可控，否决。
- 替代方案：仅精确匹配 + 报错让模型重试——往返次数高，否决。

### D2: 双世界回写模型——L1 原始字节域，L2-L4 归一化(LF)域全文件写回

L1 在原始字节上替换，其余字节不动；一旦降级到 L2-L4，匹配与替换都在归一化域完成，全文件以 LF 写回。纯 LF 文件上归一化是恒等操作，零副作用。

- 替代方案：归一化域命中后做偏移映射，仅替换原文区间——保守但需构建偏移索引，复杂度推迟到确有需要时。
- 替代方案：new_text 按原文件 CRLF 自适应转换 `\n→\r\n`——与全文件 LF 写回组合会在归一化文件中嵌入 CRLF 段，制造混合换行符，否决。统一 LF 让四层规则完全对称：old_text 宽容度逐层放宽，new_text 永远按 LF 写入。

### D3: L4 命中时 new_text 原样写入

替换区间为命中连续行的原始字节区间（首行行首至末行行尾），整体替换为 new_text 原样内容，缩进以 new_text 为准。

- 替代方案：继承原命中行的公共缩进前缀附加到 new_text 每行——new_text 自带缩进时会双重缩进，帮倒忙概率更高，否决。语义命中优先于格式保持。

### D4: 每层强制唯一性，报错附行号清单

任一层命中 ≥2 处即报错并列出各处行号（如"匹配到 3 处（第 12、45、89 行），请扩大 old_text 范围加入上下文行使其唯一"）。错误信息是驱动模型自我修正的 prompt，必须包含可行动的修正路径。

- 替代方案：替换第一处命中——静默错改位置的风险不可接受，否决。
- L4 行级 trim 去缩进后短行（`}`、空行）撞重概率高，唯一性约束在 L4 尤其重要。

### D5: 匹配逻辑实现为纯函数，两级拆分

匹配替换与文件 IO 彻底解耦，分两层抽为独立纯函数：

- 四级降级入口函数：输入 content/oldText/newText，输出新内容、行号范围、命中层级、错误；编排 L1→L4 顺序、每层唯一性检查与降级。`Execute` 只负责参数校验、路径解析与文件读写
- L4 行级匹配子函数：从入口函数中进一步抽出，输入双侧切行并逐行 trim 后的行数组与窗口大小，输出命中窗口位置（滑动窗口逐窗口比较），可独立表驱动测试

匹配算法各层为子串计数/定长窗口比较，复杂度 O(n) 至 O(m·k)，代码文件规模无需优化。测试采用纯函数表驱动 + Execute 集成测试（路径安全、文件不存在等 IO 边界）双层结构，比 write_file 仅全链路测试的覆盖更密。

## Risks / Trade-offs

- [CRLF 文件经 L2-L4 编辑后整体转 LF，产生全文件 diff] → 接受；未来如需收紧可升级 D2 为区间偏移映射
- [CRLF 文件经 L1 编辑后替换段为 LF，与其余部分混合] → 接受；Go 工具链默认 LF，主流编辑器可正常处理
- [L4 命中时 new_text 缩进错误导致代码格式变差] → 接受；语法正确性由模型后续自检（build/lint）兜底
- [L4 撞重率高导致唯一性报错频繁] → 报错附行号引导扩大上下文，模型一至两轮内可自愈

## Migration Plan

无部署与数据迁移。实现合入即对 MainLoop 生效（注册进 `NewDefaultRegistry`）；回滚等价于移除注册行与工具实现。归档时将 delta spec 同步至 `openspec/specs/tools/edit-file/`，与 write-file 并列。
